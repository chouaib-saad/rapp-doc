C. UML SYMBOL RULES (the notation is non-negotiable)
──────────────────────────────────────────────────────────────
C.1 PACKAGE = frame rect (fill none, stroke 2, package color) + its name as a
    title centered ABOVE the top edge (y = rect.y − 8), same color as frame.
    Palette: pink #C7519A, teal #2E8B9A, green #7DBB7D.
    Inner padding: ≥15px between frame and contained elements.
C.2 COMPONENT = white .box rect + TWO centered text lines: stereotype
    <<component>> (written &lt;&lt;component&gt;&gt;) at cy−4, and the component
    name at cy+14; PLUS the standard UML component icon at the top-right
    corner: translate(x+w−24, y+8) containing a 16×20 rect with two 6×4 tabs
    protruding on its LEFT at (−4,3) and (−4,11).
    BOTH stereotype and icon are mandatory — never drop either.
C.3 PROVIDED INTERFACE = "ball": circle r=11, fill #7EC8E3, stroke #333333,
    stroke-width 2.5.
    REQUIRED INTERFACE = "socket": open half-circle arc UNDER the ball:
    M cx−16 cy+7  A 19 19 0 0 0  cx+16 cy+7   (class .wire).
    SPACING LAW: the socket must NEVER touch the ball. This exact recipe
    guarantees a 3.5–5px white gap (≈3.5px at bottom, ≈5px at sides).
    Do not shrink radii or move the arc closer.
C.4 NECKS: vertical .wire from the component's bottom edge to the ball top
    (cy−11); the lower neck starts BELOW the socket at cy+17 (never at the
    ball edge, or it would cross the arc).
C.5 INTERFACE LABEL (e.g. API): .name text under the port; any wire leaving
    the port downward starts BELOW that label.
C.6 CONNECTORS: .wire paths, orthogonal segments only, elbows rounded with
    radius 10 using quadratic Béziers (Q). Terminate exactly on the target
    element's border at the mid-height of that edge. Route through empty
    corridors; never cross boxes, balls, arcs or titles.

D. PROVEN GEOMETRY HELPERS (copy into the generator verbatim)
──────────────────────────────────────────────────────────────
def package(x,y,w,h,color,title):
    title at (x+w//2, y−8) class .pkg-title fill color;
    rect(x,y,w,h) class .pkg stroke color.
def component(x,y,w,h,name):
    rect class .box; .stereo at (cx, cy−4); .name at (cx, cy+14);
    icon group at translate(x+w−24, y+8):
      rect 0,0,16,20; rect −4,3,6,4; rect −4,11,6,4 (class .icon).
def ball_socket(cx,cy):
    arc  M cx−16 cy+7 A 19 19 0 0 0 cx+16 cy+7  (class .wire)
    ball circle r=11 fill #7EC8E3 stroke #333333 stroke-width 2.5.
def neck(x,y1,y2): path M x y1 L x y2 (class .wire).
def wire(d): path d (class .wire), elbows via Q with radius 10.
